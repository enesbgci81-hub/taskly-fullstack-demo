# Taskly Fullstack Demo

A modern fullstack mobile application built with:

- Flutter (Mobile App)
- ASP.NET Core Web API (Backend)
- SQLite (Database)

This project demonstrates a simple task management system where the mobile app communicates with a backend API.

## Features

- Modern Login UI
- Task list fetched from backend API
- Glassmorphism UI design
- Gradient backgrounds
- Blur cards
- Floating action button
- Fullstack architecture

## Tech Stack

Mobile:
- Flutter
- Dio (HTTP client)

Backend:
- ASP.NET Core Web API
- Entity Framework Core
- SQLite
